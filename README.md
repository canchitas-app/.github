# canchitas-app/.github

Repo especial de la organización **Canchitas App**. GitHub aplica automáticamente estos archivos a todos los repos de la organización que no tengan una versión propia:

| Archivo | Qué hace |
|---|---|
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Convenciones de trabajo: ramas, commits, Pull Requests, secretos |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Plantilla que se precarga al abrir un PR |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Formularios para reportar bugs, pedir features y registrar tareas técnicas |

Para cambiar una regla, se edita acá (con un PR, como todo) y se aplica en todos los repos a la vez.

> GitHub exige que este repo sea **público** para que las plantillas funcionen. Solo contiene convenciones y plantillas, sin código ni datos del proyecto.
